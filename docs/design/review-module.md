# 复盘公式（①② 语义冻结）

> 日常复盘按手册顺序走：①市场 → ②风格 → ③题材/共识 → ④个股 → ⑤收口。  
> 语义以 `docs/market-regime/handbook.md` 为准。  
> **代码在 `yzdata`，不在 qlab。** `qlab.review` 已删除。  
> **2026-08-20**：① 参与度盯**成交额**（过手的钱），不盯换手/库存。换手比可留对照，不定档。  
> 对照与取数：[`yzdata/docs/review-indicators.md`](../../../yzdata/docs/review-indicators.md)。

---

## 0. 模块要回答什么

复盘不是选股库，也不是聚类库。

- **① 市场**：全场怎么变——钱有没有在转、结算宽不宽、标记价有没有骗人。对所有风格同一套尺。  
- **② 风格**：场内关注点——钱待在哪一类。短线、大盘都是这里的栖息，不是①的定义。  
- **③ 题材/共识**：钱吸到哪条故事。v1 不算。

每天收盘后填手册 §6.3 的前两行：

```text
量：__    情绪：__
风格：栖息__    五日__    当日__
```

①② 几乎全是价量 + 财务/行业，可以算完。  
③ 里「是不是一簇、赚还是亏、四勾分档」能算；「在炒什么、规则/仓位、收口 if-then」要人 + 自然语言。

定簇算法对照 [cluster-module.md](cluster-module.md)，代码在 yzdata `pockets()`。

## 2. 取数

一次拉齐，按日切片。分组特征一律 **T-1 可知**，当日收益用 T。

- 宇宙默认 `hs_a`，区间 `[start 往前 warmup 个交易日, end]`  
  `warmup = max(beta_window, mom_window, volume_window) + 1`（默认 61）
- `layer.daily`：`close`（收益）、`close_raw`×`float_shares`（流通市值）、`amount`、`is_suspended` / `is_st` / `is_limit_up` / `is_limit_down`
- 财务（成长/价值）：`layer.fundamentals` + `latest_fundamental_as_of(..., "net_profit_to_shareholders")`，PE = T-1 总市值 / 可见净利润。没有财务或有效 PE 不够 → 行业桶，不报错
- 行业（PE 不够时）：`layer.industry(..., level=1)`。成长默认电子/医药/汽车，价值默认银行/非银

活跃子集 \(U_T\)：宇宙内、未停牌、非 ST、`amount>0`、收盘价非空。  
收益：后复权 `close` 的 \(P_t/P_{t-1}-1\)。组合收益用 **T-1 流通市值加权**（贴近「钱」）。

指数对照（1000−300、创业板−红利）v1 **不算**。全市场五分位比指数更干净，Fake 源也没有这些指数。真源以后要对照，另加可选列，不改主尺。

缺宇宙或日线为空 → 抛错。财务/行业缺失 → 该轴打 0，不退出。

## 3. ① 市场

### 3.1 参与度（量档）

参与度以**成交额比**定档（过手的钱）。换手比只对照，不定档。

全市场成交额 / 换手来自指数估值（默认中证全指 `000985.CSI` 的 `get_index_valuation`），**不把个股加总**。  
聚宽换手是百分数、市值是亿元；数据源换成小数与元后，\(A_t=\) 换手 \(\times\) 流通市值。  
均量用 **不含 T** 的前 20 日：\(\bar A_t=\mathrm{mean}(A_{t-20},\ldots,A_{t-1})\)。  
\(r_t=A_t/\bar A_t\)。缩量：\(A_t<A_{t-1}\)。

| 档 | 条件（先匹配先生效） |
|----|----------------------|
| 天量 | \(r_t\ge 2.0\) |
| 天量后缩 | 近 5 日（不含 T）出现过 \(r\ge 2.0\)，今日缩量，且 \(r_t<0.8\times\) 那 5 日峰值 |
| 放量 | \(1.3\le r_t<2.0\) |
| 地量 | \(r_t<0.7\) 且缩量 |
| 正常 | 其余 |

量只说热闹，不说净流入。手册 §2.1。

### 3.2 盘面流向（2.2b，辅助列）

市场收益 \(R^{m}_t\)：\(U_t\) 的 T-1 流通市值加权。

\[
F_t=A_t\cdot\operatorname{sign}(R^{m}_t),\quad
F^{w}_t=A_t\cdot R^{m}_t,\quad
I_t=R^{m}_t/r_t
\]

涨则盘面流入，跌则流出。不是融资/北向那种边界净流入。

### 3.3 广度、虚涨、活钱层

- 上涨家数比：\(n_{+}/\) 可交易家数（未停牌、非 ST、有收盘；平盘进分母）
- 涨停 / 跌停家数（收盘）；全市场门槛按宇宙规模抬（约 0.4% / 1.5%）
- 攻防：T-1 的 20 日实现波动五分位，高波组 − 低波组
- 中位数收益、虚涨 = 市值加权 − 中位数（指数红、多数票不红）
- 活跃市值（指南针 0AMV 语义，算法是我们的代理，不是官方公式）：个股活筹比例 \(w=1-e^{-\text{换手}/\tau}\)（默认 \(\tau=2\%\)），\(0\mathrm{AMV}=\sum\) 今日流通市值 \(\times w\)。0号 = 今日流通总市值。`active_share` = 0AMV / 0号。`live_ret` = 0AMV 水平的日涨跌；`live_gap` = 该涨跌 − 0号涨跌（0号涨、0AMV 跌 = 指南针说的牛背离）。不写死 4 亿，也不用换手 1% 一刀切把票踢出 0AMV
- 活跃家数：活筹比例 \(\ge 0.5\) 的只数（只数用，不定义 0AMV 成员）
- 截面离散度：个股收益标准差
- 全市场换手 = 指数估值换手（小数）；换手比对照前 20 日。0 号流通市值仍是宇宙个股合计（活跃市值用）
- 集中度：成交额 Top1% / Top10%，对照自身 20 日均得 \(\Delta\)。档：分散 / 正常 / 聚集 / 拥挤待切（高且滞涨才待切）
- 融资余额：只用 `available_at` 已发布数（通常是 T-1），不进量档/情绪档

涨停是极端结算，不是全场温度计。上涨面宽但涨停少，① 仍可以健康，② 去写钱在权重。

### 3.4 情绪（六档 + 中性/撕裂）

**结算初判，量只确认。** 先匹配先生效。打不清就 **中性/撕裂**，不硬安「乐观」。

| 档 | 条件 |
|----|------|
| 分配 | \(r_t\ge 1.5\) 且 \(\lvert R^{m}_t\rvert<0.3\%\)（量大走不动，量在确认「走不动」） |
| 冰点/恐慌 | 跌停远多于涨停且 \(R^{m}<0\)；或中位数 \(\le -1\%\) 且跌停过门槛；或上涨比 \(\le 0.30\) 且 \(R^{m}\le -1\%\) 且攻防 \(<0\) |
| 狂热 | 上涨比 \(\ge 0.70\)、涨停 \(\ge 2\times\max(\)跌停\(,1)\) 且过全市场门槛，**并且** \(r_t\ge 1.3\)（量确认升级） |
| 乐观 | 结算已宽：上涨比 \(\ge 0.60\) 且 \(R^{m}>0\) 且涨停多于跌停；或强反弹（加权 \(\ge 1.5\%\)、上涨比 \(\ge 0.52\)、涨停多于跌停）。结算已到狂热门槛但量未确认，也落这里。地量/缩量**不否掉**。指数红中位数不红则不写乐观 |
| 认知 | 市值加权收盘在 20 日均线上方，上涨比 \(\ge 0.52\)，且「昨强组 − 昨弱组」\(>0\) |
| 修复 | 上涨比 \(\ge 0.45\) 且 \(0<R^{m}<1.2\%\)（量不挡） |
| 中性/撕裂 | 其余 |

「昨强/昨弱」= T-1 时刻可见的近 20 日涨幅头尾 20%，与风格趋势轴同一把尺。  
不把「假高潮」「配置日」写成情绪档：那是①虚热/活钱 和 ②栖息的读法。

## 4. ② 风格

四条轴，正分 = 手册「正分代表」那一侧。分组特征用 T-1，收益用 T。头尾各 20% 分位，每侧至少 `min_names`（默认 5）只，否则该轴打 0。

\[
S_t = R^{\text{高偏好组}}_t - R^{\text{低偏好组}}_t
\]

\[
M^{(5)}_t=\prod_{i=0}^{4}(1+S_{t-i})-1
\]

| 轴 | \(S>0\) | 分组（T-1） |
|----|---------|-------------|
| 规模 | 要小盘 | 流通市值 Q1 − Q5 |
| 风险 | 要弹性 | 对等权市场 60 日 β（估到 T-1）高组 − 低组 |
| 成长/价值 | 要贵的成长 | 主尺：PE 高组 − 低组（PE=T-1 市值/可见净利润，利润\(\le 0\)剔除）。有效只数不够 → 申万一级成长行业 − 银行/非银 |
| 趋势/反转 | 强者续强 | 近 20 日涨幅（截至 T-1）头 20% − 尾 20% 的 **今日** 收益 |

打分（看不清打 0）：

| \(\lvert S_t\rvert\) | 分 |
|----------------------|----|
| \(<0.3\%\) | 0 |
| \(0.3\%\sim 0.8\%\) | \(\pm 1\) |
| \(\ge 0.8\%\) | \(\pm 2\) |

PE 是「贵是否被追捧」，不是真成长。两轴分开的完整做法见 `01-capital-preference.md`；v1 只做这一根合成尺，并在 `growth_source` 写 `pe` / `industry` / 空。

再加结构（仍属 ②，不是 ③）：

| 列 | 怎么定 |
|----|--------|
| 时钟 | 换手相对 20 日均 \(\ge 1.3\) 且短动量差 \(>\) 长动量差 → `短博弈`；活跃家数升且拥挤在筑、换手 \(\ge 1.0\) 只**确认**短博弈。换手 \(<1.1\)、长动量差 \(\ge\) 短且 \(>0\)、且未聚集 → `中线`；否则 `混合` |
| 流动性 | 低换手组 − 高换手组。正 = 要低换手/配置 |
| 拥挤 | 与市场同一套 Top10 + \(\Delta\) + 档 |
| 栖息 | 看 **五日** 规模 + 流动性/时钟是否同向：大盘且配置/中线 → `权重`；小盘且博弈/短博弈 → `弹性`；否则 `混合`。单日规模分当噪声 |
| 短线细读 | 趋势轴在涨停尾巴上的分辨率。**只出相对量，不写死家数/比例档。** |

短线三根（属 ②，不是 ① 情绪，也不改栖息）：

| 列 | 怎么算 | 怎么比 |
|----|--------|--------|
| 昨涨停今日 | 昨日涨停（只数不够则空）今天等权收益 | 减等权市场 → `lu_yest_s`，用和其他轴同一套 0.3%/0.8% 打分 |
| 晋级 | 昨涨停里今天继续涨停的比例 | 减**当日**涨停率（超额），再对自身近 `short_lookback` 日算 z |
| 二板占比 | 连板 \(\ge\) `board_min`（默认 2，这是定义）/ 今日涨停 | 对自身近窗算 z。最高板只旁注，不打分 |

晋级、二板**不要**用「29%、32 家、涨停 80」这种样本占用档。z 的软/硬线在 `ReviewSpec.z_soft` / `z_hard`（默认 0.75 / 1.5 个近窗 sigma），改口径只改 spec。昨涨停相对市场能看见（\(\ge\) `score_soft`）时，只**确认**短博弈，不靠涨停家数开门。

主洋流一句话（`narrative`）先报栖息，再用五日分数拼，例如「栖息在弹性、成长、短博弈、昨涨停在赚」。  
规模跟随赚钱效应，很少改写①。大盘牛、短线冷可以同时成立。

## 5. ③ 题材/共识：先拆，不实现

手册顺序是：先定簇，再按资金共识分档，再写理由。  
**不要用概念篮子生成成员，也不要用「热不热」定义「是不是一簇」。**

### 5.1 以后用数据算（算法已冻在 cluster-module.md）

| 块 | 算什么 | 现在缺什么 |
|----|--------|------------|
| 定簇 | CAPM 残差、二级组合、pairwise 合并、核、归属 | 代码；日线+申万二级已够 |
| 赚/亏 | 热 / 冷 / 新板；个股「在炒吗、效应赚亏」 | 同上 |
| 共识四勾 | 份额、相对 1000、持续、宽度 → 苗头/达成/拥挤/破裂 | 簇先有 |
| 聚集 | 成交/涨停是否过度集中 | 有簇更好；全市场拥挤已在 ② |

这些**不要关键词，不要 LLM 定成员**。

### 5.2 以后要人工 + 自然语言

| 块 | 为什么机器先别编 |
|----|------------------|
| 理由（在炒什么） | 核上达成的那句话。涨停原因/概念只配名、拆混故事，不生成成员 |
| 规则 / 仓位印象 | 你这条规则打到第几档，不是市场状态机 |
| 收口 if-then、作废 | 情景，不是预测点位；依赖你今天认的主线 |

接口以后可以留空列：`reason`、`name_reason`、`rule_note`、`invalidation`。v1 不建这些列。

### 5.3 可选数据（有则填，无则空，仍不生成簇）

- Tushare `kpl_list` / `limit_list_ths`：涨停原因 → 只给起名
- 人工复盘文本：理由候选，要授权、要归档，不当 DataSource 默认依赖

### 5.4 v1 明确不做

定簇、新板、个股三问、共识档、涨停原因接入、LLM 起名、选股/开平仓。

## 6. Schema（v1）

一日一行，index 名 `date`。

**ReviewMarket**：量档与成交额比、换手、0AMV 活筹市值（水平 / 占 0 号 / 涨跌相对 0 号）、活筹过半家数、盘面 F/I、广度、虚涨、集中度、情绪档、已发布融资。

**ReviewStyle**：规模 / 风险 / 成长 / 趋势 / 流动性 各 \(S\)、\(M_5\)、分数；短线细读（昨涨停相对等权、晋级超额 z、二板占比 z）；`growth_source`、`clock_bin`、`habitat`、拥挤档、`narrative`。分数 ∈ {−2,−1,0,1,2}。

## 7. PIT

| 用 T-1 | 用 T |
|--------|------|
| 市值、β、PE、20 日动量、波动、行业归属、量的均量 | 当日收益、当日成交、涨跌停、激活量档/情绪 |

结构窗口不含 T，和定簇纪要同一条原则。
